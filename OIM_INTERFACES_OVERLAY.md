# Orgo Interaction Model interfaces overlay

Apply this ZIP at the root of the Orgo repository:

`C:\mycode\Orgo\Orgo`

Then rebuild/relaunch Orgo and hard-refresh the browser.

New simple surfaces:

- Today
- Workrooms
- Workroom Overview / Actions / Plan / Decisions / Evidence / People / Timeline / Review
- Intake / Report something
- Team
- Situation
- Incident / Investigation / Project Workroom modes

The overlay preserves the technical Cases/Tasks/Signals pages for compatibility and the Full Control Panel.

No database migration is required.
